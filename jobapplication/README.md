# CV Website

This repository now focuses on a single GitHub Pages-ready CV site.

## Files

- `index.html` - CV page content
- `styles.css` - page styling
- `legacy-documents/` - archive/reference materials, including the original CV source

## Publish on GitHub Pages

1. Push this repository to GitHub.
2. In repository settings, open Pages.
3. Set source to deploy from the `main` branch root.
4. Save and wait for the site URL to be generated.

Your live CV will be served from `index.html`.
